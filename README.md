# UPI Fintech Transaction Analysis

## Overview
This project analyzes UPI transaction data to identify usage trends, time patterns, and fraud indicators using Python and Power BI.
## Data preparation
The dataset used in this project was sourced from Kaggle and was already well structured and cleaned.
Jupyter Notebook was primarily used to validate the dataset, perform basic sanity checks, and separate 
the timestamp column into individual date and time features for time based analysis.
No heavy data cleaning was required, as the dataset did not contain missing values or major inconsistencies.
## Tools Used
- Python (Pandas, Matplotlib)
- Jupyter Notebook
- Power BI
- Git & GitHub

## Key Insights
- Peak UPI usage during evening hours
- Weekend transactions show higher risk signals
- Shopping and entertainment categories dominate volume
- Fraud patterns vary by merchant and bank
